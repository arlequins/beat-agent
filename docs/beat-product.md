# Beat 제품 방향

## 역할

Beat은 Arlequin 한 사람을 위한 개인 비서다. 맥과 설치 가능한 모바일 웹 앱에서
실행하며 대화, 상담, 기억, 개인 문서를 사용해 짧고 실용적인 도움을 준다. 기본
응답 언어는 한국어이며, 사용자가 요청할 때만 다른 언어로 전환한다.

반성적 대화에서는 공감, 정리, 작은 다음 행동을 제안할 수 있다. 다만 의료 또는
정신건강 진단을 하지 않고, 전문 치료나 긴급 지원을 대체한다고 말하지 않는다.

## 개인 기억과 인증 경계

- 인증된 OIDC `(issuer, subject)`가 Arlequin의 저장소와 기억을 소유한다.
- 최초 로그인에서 원하는 이름과 호칭을 묻고 이후에는 같은 인증 신원을 기억한다.
- 상담과 민감정보를 포함한 원본 대화를 장기 보존하며, 관련 있는 기억만 답변
  문맥에 검색해 사용한다.
- 문서 기반 답변은 저장된 청크와 파일명을 인용한다.
- 피드백과 학습 후보는 불변 기록으로 축적하고, 평가를 통과한 릴리스만 활성화한다.
- 기본 로컬 실행 경로는 Docker PostgreSQL, Beat OIDC, loopback Ollama다.

## 모바일 PWA

- 정적 Next.js 웹은 설치 가능한 PWA로 제공한다.
- 기존 Beat OIDC Authorization Code + PKCE와 `localStorage` 장기 로그인을 그대로
  사용한다. 설치된 PWA에서는 최초 한 번 로그인한 뒤 세션을 이어간다.
- 서비스 워커는 앱 셸과 해시된 정적 자산만 캐시한다. 대화, 상담, API 응답,
  인증 콜백과 관리자 화면은 오프라인 캐시에 저장하지 않는다.
- 모바일 브라우저의 홈 화면 설치를 안내하고 safe-area를 반영한다.

## 블로그 통합 계획

`arlequins/beat`은 별도 제품 저장소이므로 이 PR에서 수정하지 않는다. 다음 PR은
블로그에 작고 독립적인 **Beat에게 묻기** 위젯을 추가한다.

1. 위젯은 새 창 또는 명시적 사용자 동의 후 `beat-agent` 웹 앱으로 이동한다.
2. 블로그 글 맥락을 전달할 때는 URL, 제목, 발췌문을 사용자에게 보여주고 전송을
   확인받는다. 비공개 대화나 브라우저 저장소를 자동 공유하지 않는다.
3. 교차 도메인 인증, API origin, 허용된 리디렉션 URI는 실제 배포 도메인이 정해진
   뒤에만 설정한다. 개발 환경에서는 `localhost`만 허용한다.
4. 서버 간 호출이나 공개 문서 색인은 별도 위협 모델·비용 검토·회귀 평가를 통과한
   뒤에 추가한다.
